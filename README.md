# れい料理大学生 - ミステリーサイト

このサイトは、大学生「れい」の日常を描いたブログを中心とした、ブラウザで遊べるミステリー・謎解きゲームです。

## 遊び方
1. **情報を探す**: サイト内の日記やニュース記事を隅々まで読んでください。
2. **URLハック**: リンクがなくても、ファイル名やフォルダ名を推測して直接URLを打ち込むことで、隠されたページにたどり着けるかもしれません。
3. **検索窓の活用**: ニュースサイトの検索窓に、特定のキーワード（人名、場所、単語など）を入力すると、新たな真実が浮かび上がります。
   - 検索は「1単語」のみ対応しています。
   - 人名は姓名の間にスペースを入れないでください。
4. **ログイン**: IDやパスワードを要求されるページがあります。日記の中にあるヒントから正解を導き出してください。

## 目標
サイト内に散りばめられた謎を解き、以下の情報を特定し、すべてのエンディング（END1〜END4）を見つけ出してください。
- ①家の場所
- ②れいの本名
- ③犯人の正体

## 注意事項
- **このサイトはフィクションです。実在の人物、団体、事件等とは一切関係ありません。**
- 一部ホラー、不気味な演出を含みます。苦手な方はご注意ください。
- 行き詰まった時は、トップページの「ヒントページ」を参照してください。
